# 神奈川県 普通車AT限定解除 コース暗記ツール

神奈川県の普通自動車AT限定解除（普通第一種）向けの、非公式・学習用ツールです。
1号・2号コースを切り替え、模式図に走行ラインを描いて順番を練習できます。
元の二輪版の「練習 → 答え合わせ → 記録の読み込み」という使い方を参考に、新しく作成しています。

## 最初にお読みください

このツールに収録した地図は、公式PDFの画像そのものではありません。
神奈川県警察の公開図を読み取り、配置・道路形状・経路を簡略化して描き直した模式図です。
初期の参考ルートも、公式図から読み取って再構成した学習用の線であり、県警が作成・監修したデータではありません。

道路形状、車線位置、走行位置、発着位置、課題の細部などは原図と差があります。
「公式コース図」から原図を照合し、実際の受験では当日の指定コースと試験官の指示を優先してください。
再生は線上の進行順を表示するもので、実車の後退・停止・速度・車線位置・MT操作を再現しません。
自動採点や合否判定は行いません。

## PCですぐ使う

ZIPを展開し、index.html をChromeやEdgeなどのブラウザで開いてください。
画像、地図、JavaScript、CSSをHTML内に含めているため、別のファイルや外部ライブラリを読み込まずに動作します。
公式サイトへのリンクを開くとき以外は、ネットワーク接続は不要です。

管理されたPCやブラウザでは、ローカルHTMLやブラウザ保存が制限されることがあります。
保存できない場合は画面右上に警告が出ます。大切な記録は「保存・読込」からJSONファイルに書き出してください。
環境の制限でHTMLを開けない場合は、管理者に利用方法を確認してください。

## 使い方

1. 「1号コース」「2号コース」から選びます。
2. 「練習」の「描く」で、覚えている走行ラインをドラッグして描きます。
3. 「1本戻す」で直前の線を取り消し、「線をすべて消す」で現在のコースの練習線を消せます。
4. 「参考ルートのヒント」で、参考線を薄く表示できます。
5. 「答え合わせ」で自分の線と参考ルートを重ね、表示を切り替えます。
6. 再生欄で「自分の線」「参考ルート」「両方を比較」を選んで再生します。
7. 再生位置スライダー、0.5倍～4倍の速度、エリアへのジャンプを利用できます。
8. 「このコースのメモ」に復習内容を記録できます。

「両方を比較」は、2つの線の進行率を合わせて再生します。距離・所要時間・運転技能を比較するものではありません。
図中の地点番号と、再生ジャンプの連番は別のものです。
再生ジャンプのエリア名は、暗記用に付けた目安であり、公式の課題名や走行指示ではありません。

### 地図の操作

- ホイール、拡大・縮小ボタン、スマートフォンの2本指操作で拡大縮小できます。
- 「移動」またはShiftを押しながらドラッグすると地図を移動できます。
- 「100%」の部分を押すと全体表示に戻ります。
- 全画面ボタンは、ブラウザが対応している場合に利用できます。
- Spaceで再生・一時停止、Ctrl／Command＋Zで1本戻す、0で全体表示に戻します。
- 入力欄ではブラウザ標準の編集操作を優先します。Ctrl／Command＋Zは消去ボタンの操作直後も使えます。

## 記録の保存・読み込み

練習線・メモ・自分で登録した参考ルートは、コース別にこのブラウザ内へ保存します。
ログイン、サーバーへのアップロード、解析用の外部送信はありません。
別のPC・スマートフォン・ブラウザとは自動同期しません。
ブラウザのデータ削除、保存先の変更、シークレットモードなどで記録を失う可能性があります。

「保存・読込」から、2コース分をまとめてJSONに書き出せます。
読み込みでは、現在の2コース分の練習線・メモ・登録ルートを置き換えます。確認画面が表示されます。
不正な形式や地図範囲外の座標は、現在の記録を変更せずに拒否します。

対応するJSONは、このツールで書き出したものです。
二輪版の answer_route_memo.json は座標系と形式が異なるため読み込めません。
ブラウザ保存キー：kanagawa.at-course.v1

### 参考ルートを登録する

練習モードで描いた線を、「保存・読込 → 参考ルートを自分で登録する」から参考ルートとして登録できます。
複数の線は描いた順に再生します。線と線の間には補間線を足さず、再生位置が瞬間移動します。
「初期の参考ルートに戻す」で、そのコースの初期データに戻せます。練習線・メモは残ります。

## GitHub Pagesに公開する

現在の二輪版を残す場合は、別のリポジトリに配置してください。
新しいリポジトリ名の例：kanagawa-at-course-tool

1. GitHubのリポジトリの一番上の階層に index.html を配置します。展開フォルダごとではなく、中のファイルを配置してください。
2. 同梱の .nojekyll も配置できます。アプリの動作自体に必須なのは index.html だけです。
3. リポジトリの Settings → Pages を開きます。
4. Source を Deploy from a branch、Branch を main、Folder を /(root) にして保存します。
5. デプロイ後、Pagesの画面に表示された公開URLを開いてください。

この配布物は公開用のファイルです。既存リポジトリや公開サイトには変更を加えていません。
記録JSONにはメモが含まれるため、個人の記録を公開リポジトリへアップロードしないよう注意してください。

GitHub公式ドキュメント：
https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site
